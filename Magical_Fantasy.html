Magical Fantasy

  • Unity
  • C#
  • Meta SDK
  • Virtual Reality

Roles

Team Leader, VR Integrator, Enemy AI Designer

Project Timeline

2 Weeks

Team Size

5 People

Overview

Magical Fantasy is an immersive Virtual Reality Game with main focus on using Magic to traverse the fantasy world and fight against monsters or explore dungeons, disarm traps.

Goals

  • Immersive VR Game experience
  • Draw Spells to cast Magic
  • Explore Dungeon
  • Defeat enemy with spells
  • Conquer the Dungeon

Outcome

This was my first XR team project, We had a timeline of two weeks to create the core features of the game and polish things to make the experience more immersive in VR, this project was done as part of XR Bootcamp.
